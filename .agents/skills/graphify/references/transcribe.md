# Media boundary

No media download/transcription command is installed as a project recipe or invoked by this configuration. The official CLI remains installed, but semantic/media use requires its own scoped review and authorization. Do not claim that AST refresh transcribes media.

Before adding a media workflow, verify supported URL hosts, use a generic punctuation/paragraph hint when analysis output is absent (including first mixed-corpus builds), force-refresh only changed media through the supported API, and reuse cached transcripts only for unchanged media. Pass paths and transcript data through structured files/argv, never executable source. No paid model calls, dashboard or unreviewed watcher follows from this reference.
