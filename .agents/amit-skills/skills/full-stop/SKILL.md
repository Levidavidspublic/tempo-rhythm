# Full stop

You own the work all the way to a PR that is ready to merge. You never merge.

1. Build the change.
2. Prove it works: run it, run the tests, and add a screenshot for any UI change.
3. Run CI. Fix every failure. Never weaken, skip or delete a check.
4. Babysit the review bots and CodeRabbit. Fix or answer every comment.
5. When CI is green and every comment is resolved, mark the PR ready for review.
6. Never merge. Never deploy.
7. Ask Amit only when you are hard-blocked. Use the question tool. Give all the context: the goal, what you tried, the exact error, and what you need from him.

Report back: the PR link, the check results, and anything left.
