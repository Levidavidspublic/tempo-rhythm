# Takeover

You take over an existing PR or branch.

1. Read it first: the diff, the description, the comments and the CI results.
2. Decide: continue it, or use it as a reference for a fresh branch. Say which, and why, in one line.
3. Continue: push to the same branch. Don't rewrite its history unless Amit says so.
4. Reference: open a new branch and PR, and link the old PR.
5. Always credit the original author. Add a "Co-authored-by:" line to commits that use their work, and put "Builds on #N by @author" in the PR description.
6. Then finish the work with the full-stop skill.
