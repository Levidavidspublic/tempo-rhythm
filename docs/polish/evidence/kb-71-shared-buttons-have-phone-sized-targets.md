## Review repair proof

Both reported findings were reproduced before repair: [shrinking action labels](https://github.com/Levidavidspublic/tempo-rhythm/pull/1177#discussion_r4335092054) and [unconditional gallery handlers](https://github.com/Levidavidspublic/tempo-rhythm/pull/1177#discussion_r4335092088). The actual AdminApprovals revoked-row Approve button shrank to 112.34375 px at 390 px/200% root text and 88.5625 px at 320 px/200%; its single word broke across lines even though existing target and overflow checks passed. The phone rule now prevents shared buttons shrinking and lets their immediate flex action rows wrap, preserving explicit `flex-nowrap` callers. At both widths the repaired Approve measures 133.734375 px, Revoke 120.5625 px and Back to pending 237.203125 px with computed 28 px text. All five controls at both widths and both 100%/200% root text keep whole words, remain inside their actual list rows, have targets of at least 44 by 44 px and cause no document overflow. The regression waits for and asserts computed 14/28 px button text before measuring; an initial passing run exposed a font-update measurement race during screenshot inspection, so the stronger assertion and final capture supersede that run.

The callback-free pure gallery previously supplied nine function-valued button `onClick` props; a direct assertion failed before repair. It now leaves handlers undefined when optional callbacks are absent in both locales. Mounted clicks still report exactly `small, default, large, icon, destructive, ghost, linkStyle, long`; the disabled sample stays inert, and the supplied link callback retains its identity. No client directive, hook, variant, native type, public export, caller or backend was changed. All original 20 test names, assertions and fixture timeouts remain; the three review regressions are additive. Browser build/server state stays inside the existing clean child process, and its parent rejects any nonzero child exit before consuming results.
