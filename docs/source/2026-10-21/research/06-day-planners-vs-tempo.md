# 06 · Day planners versus Tempo Flow

**Verdict:** This report compares the most popular planners on price, cost per user, architecture, features and AI use. Then it shows where Tempo Flow is different. It feeds step 6.

**Where to run it:** Perplexity, Google deep research, ChatGPT deep research and Claude research. Use the same prompt in each one.

**What to attach:** nothing.

Paste from here:

```
I am a solo founder in Israel. I am building Tempo Flow, an ADHD-friendly daily planner. It is agent-first: an AI agent does the planning and the data entry, so the user doesn't type everything in. It costs $20 or $50 a month. My own estimate of the AI model and voice cost is about $3 a month per user on the $20 plan. Voice is capped, because a heavy voice user could cost much more.

Tomorrow I am explaining to a family member, a businessman who is not technical, why Tempo Flow is priced as it is and how it differs from the popular planners. I need accurate, sourced facts and clearly marked estimates.

THE APPS
Sunsama, Akiflow, Notion, Todoist, Craft, TickTick, Things, Motion, Reclaim, Tiimo and Structured.

QUESTIONS

1. Price. For each app, give the price per user per month, billed monthly and billed yearly. Include the free tier and the price of any AI add-on.

2. Scale. For each app, give public figures on users, revenue and funding, where they exist.

3. Cost to serve one user. For each app, estimate the monthly cost to serve one user: hosting, sync and AI. Give a low and a high figure. Show the method for every estimate. Mark every estimate EXTRAPOLATED. Use public infrastructure statements, engineering blogs and SaaS gross-margin benchmarks.

4. Architecture. For each app: is it cloud-based or local-first? How does sync work? Does it work offline? Which platforms does it run on? Which integrations does it have, such as calendar and email? Does it have a public API?

5. Features. For each app, describe its planning model: time-blocking, task lists, a daily planning ritual or automatic scheduling. List any features made for ADHD or executive-function needs.

6. AI use. For each app: what does the AI do? Which model provider does it use, if that is public? What usage limits apply? Is the AI agent-first, so it does work without the user typing, or assistive, so the user types and the AI helps? Does the user still enter most data by hand?

7. Summary table. One row per app: price, AI included or extra, agent-first or manual-first, estimated cost per user.

8. Tempo Flow. Using only the sourced facts above, explain where an agent-first planner like Tempo Flow fits. Compare its price and its cost per user with the others. Explain what is structurally and technically different. Label this section ANALYSIS.

HOW TO ANSWER
- Research window: November 2025 to October 2026. Use older sources only if nothing newer exists. Label them OLDER, with their date.
- Source order: primary sources first. These are official pricing, help and terms pages, company announcements, engineering blogs and filings. Then major news outlets and named analysts. Treat blogs, forums and videos as leads only, and label them UNVERIFIED.
- For every figure, give the source name, the author if any, the publication date, the URL, and a short direct quote under 25 words.
- If you cannot find something, write UNKNOWN. Never present a guess as a fact. If you estimate, show the sum and label the result EXTRAPOLATED.
- If a price changed during the window, give the newest price and its date.
- Answer every numbered question under the same number, even when the answer is UNKNOWN. I will compare your answer with other research tools, line by line.
- Writing style: I have dyslexia and use read-aloud. Use short, plain sentences. One idea per sentence. Explain any jargon the first time you use it. Use a table only for side-by-side numbers.

OUTPUT
1. Verdict: five sentences at most.
2. Answers, numbered to match the questions.
3. UNKNOWN: everything you could not confirm.
4. Sources: the full list, with dates and URLs.
```
