# Contract B03: brain dump, adaptive coach, nags and memory

Data ticket: TEMPO-B03-01 (scope `convex/` only). Components call ONLY the names below.
NEW = built by TEMPO-B03-01. EXISTING = already in the code. Every function requires a signed-in user (`requireUser` from `convex/lib/requireUser.ts`) and only touches that user's rows.
Locks (PRD §6): the model never writes to the database (actions return proposals; mutations written in code do the writing); crisis words return a fixed card with no model call; no shame copy.

## Shared shapes
- `Memory` = `{ _id: Id<"memories">, content: string, sector: "semantic"|"episodic"|"procedural"|"emotional"|"general", salience: number, createdAt: number, updatedAt: number, lastAccessed: number }`
- `NagPhrase` = `{ id: string, text: string, source: "user"|"derived", status: "proposed"|"accepted"|"rejected" }`
- `Nag` = `{ _id: Id<"nags">, label: string, enabled: boolean, phrases: NagPhrase[], createdAt: number, updatedAt: number }`
- `CoachProposal` = `{ _id: Id<"coachProposals">, status: "pending", tasks: { taskId: Id<"tasks">, title: string, minutes: number }[], tenSecondAction: string, realism: { ok: boolean, totalMinutes: number, availableMinutes: number, note: string }, createdAt: number }`
