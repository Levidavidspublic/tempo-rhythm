# Contract B01 — Daily planner

Batch B01 (theme: daily planner). Screens: `/today`, `/plan` (Day view), `/habits`, `/habits/[id]`.
Source: docs/PRD.md §4.1 ("Added 3 Oct: daily planner by Sunday morning"), §5, §6; docs/BACKEND-SCHEMA.md §3; docs/APP-FLOW.md §5.

Conventions (all NEW functions):
- Every function calls `requireUser(ctx)` (convex/lib/requireUser.ts) and only touches the caller's rows.
- `localDate` is `"YYYY-MM-DD"`, computed in the browser (the server has no user time zone).
- `startMinute` is minutes since local midnight (0–1439); `startsAtMs` / `endsAtMs` are absolute instants computed by the client.
- Deletes are soft (`deletedAt = Date.now()`); reads filter `deletedAt === undefined`.
- Copy rule (PRD §6): never shame. Skipped blocks and missed days are neutral. No "failed", "streak lost", "overdue".

Shared shapes:
- `DayPlan` = `{ _id: Id<"dayPlans">, _creationTime, userId, localDate: string, timezone?: string, intention?: string, topTaskIds?: Id<"tasks">[] (max 3), energy?: "low"|"medium"|"high", status: "draft"|"committed", committedAt?: number, reflection?: string, createdAt, updatedAt, deletedAt? }`
- `TimeBlock` = `{ _id: Id<"timeBlocks">, _creationTime, userId, localDate, dayPlanId?: Id<"dayPlans">, title: string, startMinute: number, durationMinutes: number (5–720), startsAtMs: number, endsAtMs: number, kind: "focus"|"task"|"habit"|"break"|"other", taskId?: Id<"tasks">, habitId?: Id<"habits">, status: "planned"|"done"|"skipped", source: "user"|"coach", createdAt, updatedAt, deletedAt? }`
- `HabitCheckIn` = `{ _id: Id<"habitCheckIns">, _creationTime, userId, habitId: Id<"habits">, localDate, checkedAt: number, source: "habits"|"today"|"suggestion"|"legacy", note?: string, createdAt, updatedAt, deletedAt? }`
- `Task` and `Habit` = the existing row shapes (convex/schema.ts `tasks`, `habits`; `Task` as `taskReturnValidator` in convex/tasks.ts).

## NEW functions (built by TEMPO-B01-01)

| Function | Kind | Args | Returns | File |
|---|---|---|---|---|
| `api.dayPlans.getForDate` | query | `{ localDate: string }` | `DayPlan \| null` | convex/dayPlans.ts |
| `api.dayPlans.upsert` | mutation | `{ localDate: string, timezone?: string, intention?: string, topTaskIds?: Id<"tasks">[] (max 3, owned by caller), energy?: "low"\|"medium"\|"high" }` | `Id<"dayPlans">` (creates a `draft`; patches an existing plan, never un-commits it) | convex/dayPlans.ts |
| `api.dayPlans.commit` | mutation | `{ localDate: string }` | `{ dayPlanId: Id<"dayPlans">, committedAt: number }` (creates the plan if missing; idempotent) | convex/dayPlans.ts |
| `api.dayPlans.listCarryOver` | query | `{ beforeMs: number }` (start of the local day) | `Task[]`: non-deleted tasks with `status` `todo`/`in_progress` and `dueAt < beforeMs`, sorted by `dueAt` ascending, max 50 | convex/dayPlans.ts |
| `api.dayPlans.moveTaskToDay` | mutation | `{ taskId: Id<"tasks">, dueAt: number }` | `Id<"tasks">` (patches `dueAt` and `updatedAt` only) | convex/dayPlans.ts |
| `api.timeBlocks.listForDate` | query | `{ localDate: string }` | `TimeBlock[]` sorted by `startMinute` | convex/timeBlocks.ts |
| `api.timeBlocks.create` | mutation | `{ localDate: string, title: string, startMinute: number, durationMinutes: number, startsAtMs: number, endsAtMs: number, kind: "focus"\|"task"\|"habit"\|"break"\|"other", taskId?: Id<"tasks">, habitId?: Id<"habits"> }` | `Id<"timeBlocks">` (`status: "planned"`, `source: "user"`; links the day plan if one exists) | convex/timeBlocks.ts |
| `api.timeBlocks.update` | mutation | `{ timeBlockId: Id<"timeBlocks">, title?: string, startMinute?: number, durationMinutes?: number, startsAtMs?: number, endsAtMs?: number, kind?: "focus"\|"task"\|"habit"\|"break"\|"other" }` | `Id<"timeBlocks">` | convex/timeBlocks.ts |
| `api.timeBlocks.setStatus` | mutation | `{ timeBlockId: Id<"timeBlocks">, status: "planned"\|"done"\|"skipped" }` | `Id<"timeBlocks">` | convex/timeBlocks.ts |
| `api.timeBlocks.remove` | mutation | `{ timeBlockId: Id<"timeBlocks"> }` | `{ success: true }` (soft delete) | convex/timeBlocks.ts |
| `api.habitCheckIns.listForDate` | query | `{ localDate: string }` | `HabitCheckIn[]` (all habits, that local day) | convex/habitCheckIns.ts |
| `api.habitCheckIns.listForHabit` | query | `{ habitId: Id<"habits">, fromLocalDate: string, toLocalDate: string }` (inclusive) | `HabitCheckIn[]` sorted by `localDate` ascending | convex/habitCheckIns.ts |
| `api.habitCheckIns.check` | mutation | `{ habitId: Id<"habits">, localDate: string, source: "habits"\|"today"\|"suggestion", note?: string }` | `{ checkInId: Id<"habitCheckIns">, alreadyChecked: boolean, currentStreak: number, longestStreak: number }` (one per habit per local day; recomputes the `habits` cache fields) | convex/habitCheckIns.ts |
| `api.habitCheckIns.undo` | mutation | `{ habitId: Id<"habits">, localDate: string }` | `{ removed: boolean, currentStreak: number, longestStreak: number }` (soft delete; recomputes the cache) | convex/habitCheckIns.ts |
| `api.habits.get` | query | `{ habitId: Id<"habits"> }` | `Habit \| null` (null if missing, deleted or not the caller's) | convex/habits.ts |
