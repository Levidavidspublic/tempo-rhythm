# Contract B04: Templates, account and settings

Data ticket: TEMPO-B04-01 (convex/ only). Components call only the names below.
Ids: starter templates use string ids `starter:<slug>`; user templates use `Id<"templates">` (a string in URLs).

## Shapes
```
Template = { templateId: string, source: "starter" | "user", name: string, description?: string,
             periodType: "daily"|"weekly"|"monthly"|"none", sections: string[], body: string (markdown), updatedAt?: number }
Preferences = { theme: "system"|"light"|"dark", locale: "en"|"he", weekStartsOn: 0|1|6, timeZone: string,
                emailReminders: boolean, inAppNotifications: boolean }
Notification = { _id: Id<"notifications">, title: string, body: string, kind: "system"|"reminder"|"billing", readAt?: number, createdAt: number }
```
