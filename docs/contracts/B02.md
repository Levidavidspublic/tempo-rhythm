# Contract B02 — Calendar, tasks, notes, tracking and insights

Batch B02. Data ticket: TEMPO-B02-01 (convex/ only). Components call ONLY the names below.
Every function checks `requireUser` and filters by `userId`; the server sets `userId`.
Soft delete (docs/PRD.md §5 "Soft delete", TRD §7.4): a delete sets `deletedAt`; the UI may undo for 5 minutes
(`UNDO_WINDOW_MS = 300000`); rows stay restorable for 30 days (`GRACE_MS = 30 * 86400000`). Both constants live in
`convex/lib/softDelete.ts` (NEW). `undoUntilMs = deletedAt + UNDO_WINDOW_MS`.
