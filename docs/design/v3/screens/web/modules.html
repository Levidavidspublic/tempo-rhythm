Scheduled jobs

Things Tempo does on a schedule. Each run writes into a page.
  • Morning plan Mon–Fri 08:00 Last ran today at 08:00 · wrote a plan into Today
  • Sunday week look-back Sun 18:00 Last ran Sun 11 Oct at 18:00 · wrote into Week 42
  • Bills check 1st of month 09:00 Last run on Thu 1 Oct didn't finish. Nothing was changed. It's off until you turn it back on.
