CONTRACT:
Exact proposed KB-16 API and budgets; all endpoints live in existing modules so `_generated/api.d.ts` needs no edit.
```ts
type SearchOptions = { mode: "speed" | "balanced" | "quality";
  sources: ("web" | "discussions" | "academic")[]; domains: string[] };
type SearchRow = { title: string; site: string; url: string; snippet: string;
  imageUrl: string | null; thumbnailUrl: string | null;
  durationSeconds: number | null; publishedAt: number | null };
search.capabilities // query, authenticated owner, no credentials in response
  ({}) -> { enabled: boolean; modes: ("speed"|"balanced"|"quality")[];
    sources: ("web"|"discussions"|"academic")[];
    categories: ("web"|"images"|"videos"|"discover")[] };
search.lookup // action, approved user, explicit click only
  ({ query: string, options: SearchOptions,
     category: "web"|"images"|"videos"|"discover" })
  -> { status: "ok"|"off"|"limit"|"unavailable"|"unsupported"|"crisis";
       rows: SearchRow[]; retrievedAt: number | null; truncated: boolean };
coach.reply // existing action, additive optional argument; return unchanged
  ({ conversationId: Id<"conversations">, noteId?: Id<"notes">,
     dayStartMs?: number, dayEndMs?: number, todayDate?: string,
     searchOptions?: SearchOptions })
  -> { status: "replied"|"unavailable"|"idle"|"busy"|"superseded" };
```
Default is balanced + [web] + []. Query 1–200 Unicode code points; 1–3 distinct source families; at most five hostname domains. Invalid input yields `ConvexError({code:"invalid_search_options"})` or `invalid_query`. Validate IDNA hostname, lower case, remove trailing dot, refuse credentials, paths, nondefault ports and IP literals. Accept results only when their hostname equals an allowed host or ends in `.` + that host; `example.com.evil.test` never matches. Strip provider HTML as text. Match source families by a documented SearXNG engine/category allowlist from KA-24's deployed version; unsupported families return unsupported, never silently widen to web. Domain filters apply after result validation as well as in the provider query.

Speed: one search, top 3 sources, no page reads, 8 s retrieval deadline. Balanced: one search, top 5, no page reads, 12 s. Quality: one search, top 5, at most 2 safe page reads, total 20 s retrieval deadline, at most the existing `COACH_LIMITS` input budget. Same existing ai_router model tier, token ceilings and at most the existing two model calls for a searched coach turn. Quality improves source context only; no new agents, model, paid provider, embedding, key or allowance. If an existing adapter cannot obey a deadline without editing an out-of-scope file, disable that capability and report UNKNOWN; do not use a timeout race that leaves background fetches running.

`search.lookup` does not call a model. It reserves one unit in the existing `coachWebSearches` counter by a new internal mutation `search.reserveLookup({}) -> {status:"reserved"|"off"|"limit"}`, checks the same preference and approved owner, and shares the ten-per-UTC-day limit with coach search. Store only the content-free reservation. Add it in search.ts; do not create another budget or reset the current one. `search.lookup` checks crisis text before any external request. Media max 12 results; Discover max 10; web max 5. No per-keystroke suggestions network endpoint, no automatic Discover refresh. Return off when KA-24 SearXNG is unset; do not fall through to a paid search provider for these new features. Existing legacy coach behavior without searchOptions stays unchanged.

All page/thumbnail/source URLs pass KA-24 URL safety validation and HTTP(S) checks. Before the initial server fetch and every redirect hop, the merged KA-24 checkFetchUrl/fetchPageText boundary must reject loopback, private, link-local, metadata and other non-public destinations, including IPv6, mapped IPs and hostnames resolving to forbidden addresses. A protocol-only safeUrl check is insufficient. Verify the destination used for the connection and prevent DNS rebinding; never automatically follow an unchecked redirect. If the merged prerequisite lacks these protections, disable the affected capability and report blocked: KA-24 URL safety; do not edit its out-of-scope module. Fetches use redirect checks and real cancellation; no server image proxy is added. Provider snippets, fetched pages and media metadata stay in RAM. Only current `{title,site,url}` citations may be saved with a coach answer; external snippets never become instructions or accepted user data. Do not add raw tool payloads to messages. Caller-side media/Discover state is cleared on account change.
